## 🚀 Features
- Upload Avatar with preview
- Live form to enter name, email, GitHub handle
- Generates a ticket with user info
- Fully custom UI 

##  Folder Structure
```
src/
  components/
  pages/
  App.js
  index.js
```

##  How to Use
```bash
npm install
npm run dev
```
Go to `http://localhost:3000/` for ticket form generation.
Go to `http://localhost:3000/ticket` for showing ticket results.

##  Components
- `AvatarUpload`
- `InputField`
- `Button`
- `TicketCard`
- `LogoHeader`
